# Keep, replace, or combine

Use this when a draft exists and the question is whether to keep it, replace it, or combine it with something else. Do not edit the draft.

Take constraints from what the user actually said. A claim that appears only in the draft is not a requirement.

Look for alternatives before comparing. Compare them and the draft on the same criteria. If you find no alternative, say so and still choose.

Choose keep, replace, or combine, and say why that choice is feasible. If a fact or preference is missing, choose and say what you assumed. Leave it unresolved only when the user asked to leave it open, and still say what you would have done. An unresolved choice does not start a revision.
